# GZL Roleplay v1.0

Piyasadaki çöp ve açık dolu paketlerle karıştırmayın. Uğraşacak vaktim kalmadığı için salıyorum. 

XAMPP, MySQL veya Navicat kurmaya kalkmayın, altyapı tamamen SQLite. Çift tıkla aç oyna.

### Özellikler

- Tamamen taşınabilir SQLite (Zero-Config, veritabanı kurma derdi yok)
- 6 aşamalı özel launcher (scriptler çakışmadan sıralı başlar)
- Anticheat ve güvenlik (event spam, para bugları, gps açığı kapalı)
- OX tarzı CEF envanter (sürükle-bırak, yere eşya atma)
- FiveM stili karakter oluşturucu
- txAdmin DX yönetim menüsü
- LSPD tablet, EMS, Mekanik, Taksi, Cam Temizleme, Blackjack
- Dinamik yakıt, vale ve gerçekçi araç sesleri
- Cylex telefon
- GTA V dairesel minimap ve GPS

### Tuşlar

- F1: Telefon (/telefon)
- F2 / I: Envanter
- Page Up: txAdmin (Admin yetkisi gerekir)
- M: İmleç (/cursor)
- J: Motor
- X: Eller yukarı
- V / Home: FPS kamera
- Sol Alt (LAlt): Telsiz
- T: Sohbet

### Kurulum ve Yetki

1. MTA Server64.exe dosyasını çalıştırın.
2. Sunucu konsoluna şu komutu yazarak direkt Seviye 10 Kurucu yetkisi verin:
```cmd
setadmin thommy 10
```
*(Oyuncu ID, nick veya hesap adıyla verilebilir. Seviye 8+ adminler oyun içinden de `/setadmin` kullanabilir.)*
